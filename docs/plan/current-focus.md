## Rules for this focus
1. **Grow it out of the teleop code:** extract what exists; formal interfaces only when a second real user needs them.
2. **Fake first, offline first:** every step runs without hardware and (except the AI steps) without internet. Robot tools run on the fake arm before a real one.
3. **Only claim what's real:** the start screen, status strip and panels never show a check or number that didn't happen; what isn't real yet is left out.
4. **The design for new and changed pages** (`docs/design/DESIGN.md`, `config/theme.yaml`); `/` stays plain by default (`hub.look: plain`) and the plain pages keep working.
5. **The hub's built-in assistant reads, answers and opens pages** on the device it's talking at (anyone in the room can talk to it; moving the arm from it is an idea, except the fixed wave of visitor mode, which it may start, quick job 35, and preview 4 (2026-11-19/20): a named pose and the cube's hand-over, off unless Settings allows it; more abilities may come, so it's not a hard rule that it never changes anything, the builder 2026-11-14). **With ⚙ → Assistant → Full Access on (quick job 80, the builder 2026-11-21), it gets every tool of the brain**, the move and picture tools included; off by default; safety for it comes later. The move tools are for a developer's AI tool on the brain's computer, through the same safety layer as teleop. Since 2026-11-13 they don't ask before each move (quick job 1, built 2026-11-14); STOP on every screen, the soft joint limits and one controller at a time always stay. Code written by AI goes branch → tests → merge; a session merges its own PR once the tests pass; only a critical change (one that weakens a safety rule, the green arms' rules or the permission settings) waits for the builder (AGENTS.md, 2026-11-20).
6. **Secrets** (API keys) only in `.env`; `.env.example` lists the names.
7. **Portable:** Linux, Windows, macOS. **Plain names** in code, show names in persona files.
8. **The green arms:** AGENTS.md's four rules (the code follows them since step 11).
9. **Nothing place-specific in code:** the lab's name, devices, venues and personas live in config (`docs/dev/places.md`).
