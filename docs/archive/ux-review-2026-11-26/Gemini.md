# UX and UI Review — `maximal` Look (Gemini)

Review scope: code-only audit of all 19 pages in `PAGES`, all hub modals, shared chrome (`kit.css`, `kit.js`, `fullscreen.js`), and VR/AR modules (`xr-hub.js`, `xr/*.js`, `teleop/web/xr-scene.js`), visually verified against existing `maximal` screenshots in `docs/archive/ux-review-2026-11-26/Codex/`.
Format per line: `Page | Size & look | Problem | Suggested fix | Severity | Evidence / tags`.
Tags: `[builder]` = builder's requested change; `[overrules DESIGN.md]` = recommendation intentionally overrules a rule in `docs/design/DESIGN.md`; `from the code` = inspected from source code (used on all VR/AR items and code-only findings).

## Across Many Pages
